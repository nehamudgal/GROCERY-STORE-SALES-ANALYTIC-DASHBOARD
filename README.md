# Grocery Store Sales Analytics Dashboard

## Overview

This Power BI dashboard provides insights into grocery store sales performance, order trends, customer ratings, and product category analysis. It enables users to explore key business metrics through interactive visualizations and filters.

## Features

* Sales and Order Performance Tracking
* Average Sales and Customer Rating Analysis
* Category-wise Sales Breakdown
* City Tier-wise Sales & Orders Analysis
* Shop Type Performance Comparison
* Interactive Filters for Dynamic Reporting

## Tools Used

* Power BI
* Power Query
* DAX
* Excel/CSV

## Key KPIs

* Total Sales
* Total Orders
* Average Sales
* Average Rating

## Skills Demonstrated

* Data Cleaning & Transformation
* Data Modeling
* DAX Calculations
* Dashboard Design
* Data Visualization
* Business Intelligence
